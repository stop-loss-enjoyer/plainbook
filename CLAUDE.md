# Plainbook

**Read [AGENTS.md](AGENTS.md) first.** It is the working guide for this
repository: whose data this is, how to run and verify a change, the map of the
code, the invariants that must not be broken, and the traps that have already
bitten. This file only adds what is specific to talking with the owner.

The person using this journal is a trader, not a developer. Talk in their
language, show the result rather than the code, and keep explanations about
their trades rather than about your implementation.

- If the journal is not installed on this machine yet, start with
  [INSTALL.md](INSTALL.md).
- When they ask "how do I…", the answer is usually already in [GUIDE.md](GUIDE.md).
  Point at it, and keep it current when the interface changes.
- Trades and cards are entered through the web interface, not by editing files.
  If they ask you to fix a file directly, do it, then run the tests and check
  that the page still renders.
- Do not quote the contents of their trades without need. Summary figures answer
  almost every question.
